Cloudflare Integration Setup

Why Cloudflare?

Cloudflare integration provides robust storage for your contacts and files with several advantages:

  • Global distribution - files load quickly anywhere in the world
  • Deduplication - files shared with multiple contacts are stored only once
  • Cost-effective - pay only for what you use with no minimum fees
  • Reliable backups - data is automatically replicated across multiple regions

1. Install Wrangler CLI

npm install -g @cloudflare/wrangler

2. Authenticate with Cloudflare

wrangler login

3. Create R2 Bucket for File Storage

wrangler r2 bucket create central-files

4. Create D1 Database for Metadata

wrangler d1 create ADCS_DB
wrangler d1 migrations create init_schema --database ADCS_DB

Create migrations/init_schema.sql with this schema:

CREATE TABLE files (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  key TEXT UNIQUE,
  name TEXT,
  mime TEXT,
  size INTEGER,
  uploaded_at TEXT
);
CREATE TABLE contacts (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  email TEXT UNIQUE,
  name TEXT,
  last_contacted TEXT,
  unsubscribed INTEGER DEFAULT 0,
  metadata TEXT
);
CREATE TABLE file_contacts (
  file_id INTEGER,
  contact_id INTEGER,
  is_original INTEGER DEFAULT 0,
  UNIQUE(file_id, contact_id)
);

5. Create KV Namespace for Aliases

wrangler kv:namespace create "FILE_ALIASES"

Note the ID returned by this command for your wrangler.toml file.

6. Create wrangler.toml Configuration

name = "adcs-worker"
type = "javascript"
account_id = ""
workers_dev = true
route = ""

# Bind your R2, D1, and KV
[[r2_buckets]]
binding = "R2_BUCKET"
bucket_name = "central-files"

[[d1_databases]]
binding = "D1_DATABASE"
database_name = "ADCS_DB"

[[kv_namespaces]]
binding = "KV_NAMESPACE"
id = ""

7. (Optional) Set OpenRouter API Key

wrangler secret put OPENROUTER_API_KEY

When prompted, paste your OpenRouter API key.

8. Deploy and Migrate

wrangler d1 migrations deploy --database ADCS_DB
wrangler publish
